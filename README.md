# Amirthaa R — AI/ML Portfolio

A responsive dark-theme personal portfolio built with plain HTML, CSS, and JavaScript.

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_BRAIN_TUMOR_COLAB_LINK` with your actual shareable Google Colab URL.
3. Check every GitHub repository URL and remove links for repositories that do not exist or are not public.
4. Replace the internship placeholder with tasks you actually completed.
5. Add a resume PDF link if you want to offer a downloadable resume.
6. Verify the paper's current status before describing it as under review, accepted, or published.
7. Confirm the GPA, education date, bootcamp date, and all listed tools are correct.

## Preview locally
Open `index.html` in a browser. No build tools or installation are needed.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** and set the deployment source to the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish. The site should appear at `https://YOUR-USERNAME.github.io/`.
5. Add that URL to your resume and LinkedIn.

## Notes
- This portfolio intentionally avoids inventing project metrics beyond the 93.62% test accuracy stated in the project materials.
- Project URLs are prefilled from repository names mentioned by the user; verify each URL before publishing.
